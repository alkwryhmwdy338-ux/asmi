# asmi

A Flutter app with a dark theme and a bottom navigation bar. Each screen is isolated in its own file.

## Run locally

```bash
flutter pub get
flutter run
```

## Project structure

- `lib/main.dart`
- `lib/app.dart`
- `lib/widgets/bottom_nav.dart`
- `lib/screens/home_screen.dart`
- `lib/screens/search_screen.dart`
- `lib/screens/wallet_screen.dart`
- `lib/screens/profile_screen.dart`

## Notes

This version focuses on the navigation structure and screen isolation requested for the project.
