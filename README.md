# Swap UI Demo

واجهة HTML/CSS/JS تجريبية مبنية لتقريب تصميم شاشة الـSwap المرجعية التي أرسلتها.

## الملفات
- `index.html`
- `style.css`
- `script.js`

ضع الملفات في جذر مستودع GitHub ثم فعّل GitHub Pages من:
Settings → Pages → Deploy from a branch → main → /(root) → Save

> هذه نسخة واجهة تجريبية وليست نظام تداول حقيقي، ولا تحتوي على توقيع معاملات أو اتصال فعلي بمحفظة.
